# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of
conduct.

The full text is published at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md

By participating in this project — submitting issues, pull requests, code
review, or discussion — you agree to abide by its terms.

## Reporting

To report a concern, contact the maintainer at **sawanruparel@gmail.com**.
Reports are handled confidentially and acknowledged within 7 days.
